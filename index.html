Projects

Everything below is public. Each entry links to its repository, with a short note on what it is for and where to start.

ADS-B aircraft receiver

A palm-sized receive-only ADS-B board: power it at 3.3V, fit the antenna, and your laptop, Raspberry Pi or drone ground station sees the aircraft around you live — callsign, position, altitude, speed, heading. No internet, no subscription, no running cost.

  • Product page on this site: ADS-B Receiver
  • Repository: jumbo5566/adsb-module
  • Browser serial terminal (in the repo): Web-serial-at.html — Chrome / Edge / Opera over http://localhost, AT commands as one-click buttons, 115200 8N1
  • Viewer tool (in the repo): python mavlink_decoder_win.py COM25 115200

DX-888 manuals (TEF6686 receiver)

Documentation for the DX-888 radio receiver module built around the NXP TEF6686 tuner IC. Both editions are kept as PDFs inside the repository, so the links never point at an external download page.

  • Repository: jumbo5566/manuals
  • English edition: DX-888.pdf
  • Chinese edition: DX-888CN.pdf

Flow Station

Open-source amateur-radio station software: an ESP32-based audio and control layer that ties a transceiver to Asterisk / AllStar / DMR / YSF / P25 / NXDN style digital voice links, with a web console for configuration and monitoring.

  • Repository: jumbo5566/flowstation (main branch)
  • Upstream project: razvanzeces/flowstation
  • Start from README.md and the example_config folder in the repository

Brew server

Server side of the Brew hub ecosystem: federation, console, SDS messaging and relay services that the Flow Station firmware talks to.

  • Repository: jumbo5566/brew-server (main branch)
  • Upstream project: ysamouhos/brew-server
  • Sample configuration lives in the sample/ folder of the repository
